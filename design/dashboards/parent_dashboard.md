# Parent Dashboard

The parent dashboard gives families a clear view of student progress, upcoming responsibilities, teacher feedback, and billing.

## Primary Goals

- Understand how each linked student is doing.
- See urgent academic or payment issues.
- Review teacher feedback and monthly reports.
- Move quickly to payments or communication.

## Layout

- Family overview header with child switcher and quick status summary.
- Top metrics for progress, attendance or engagement, due assignments, and payments.
- Main grid with child progress, upcoming academic work, teacher feedback, and finance.
- Right rail for alerts and recommended parent actions.

## Core Widgets

- Child Switcher: quick access to each linked student.
- Progress Overview: course progress, completion trend, quiz average.
- Upcoming Work: due assignments, upcoming quizzes, missed tasks.
- Teacher Feedback: latest comments and recommendations.
- Payment Summary: invoices due, paid history, wallet balance when available.
- Alerts: overdue assignments, engagement drops, payment issues.
- Reports: monthly or weekly academic summaries.

## Premium SaaS Details

- Prioritize readability and trust over visual density.
- Use plain language for academic status.
- Use blue for progress, green for positive performance, orange for concern, red for urgent issues.
- Use purple sparingly for selected child context or primary action.

## Parent Workflows

- Switch child.
- Pay invoice.
- View academic report.
- Message teacher.
- Review overdue work.
- Adjust notification preferences.

## Responsive Behavior

- Desktop: child summary, reports, and alerts visible in a balanced dashboard grid.
- Tablet: child switcher remains prominent and finance moves below academic cards.
- Mobile: selected child, urgent alerts, and payment due status appear first.
