# Student Dashboard

The student dashboard is a focused learning home. It should help students know what to continue, what is due, and how they are progressing.

## Primary Goals

- Continue the next lesson quickly.
- Understand upcoming assignments and quizzes.
- Show progress in a motivating, clear way.
- Surface teacher feedback and important alerts.

## Layout

- Top learning path panel with next lesson, course progress, and continue action.
- Metric row for enrolled courses, completed lessons, quiz average, and due items.
- Main area with current courses, upcoming work, and recent feedback.
- Optional right rail for streaks, achievements, or study recommendations.

## Core Widgets

- Continue Learning: next lesson, current course, progress bar.
- My Courses: enrolled courses with CourseCards.
- Upcoming Work: assignments, quizzes, deadlines.
- Recent Feedback: teacher comments, graded submissions, quiz results.
- Progress Snapshot: completion rate, study time, streaks.
- Alerts: overdue work, access issues, payment restrictions when applicable.

## Premium SaaS Details

- Keep the interface calmer than admin and teacher dashboards.
- Use large clear primary action for continuing learning.
- Use green for completed progress and blue for academic progress charts.
- Use orange for deadlines and red only for overdue or blocked access.
- Avoid overwhelming students with too many analytics at once.

## Student Workflows

- Continue lesson.
- Start quiz.
- Submit assignment.
- Review feedback.
- Open course progress.

## Responsive Behavior

- Desktop: learning panel, course cards, and upcoming work visible together.
- Tablet: continue panel remains first, courses and upcoming work become two columns.
- Mobile: continue action first, then due work, then courses, then feedback.
