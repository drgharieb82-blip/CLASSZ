# Teacher Dashboard

The teacher dashboard is the daily teaching cockpit. It should make the next teaching action obvious while preserving deep access to courses, lessons, assignments, students, and assistants.

## Primary Goals

- Continue course creation and teaching work quickly.
- Identify students who need attention.
- Review submissions, quizzes, and grading tasks.
- Coordinate assistants and upcoming academic activity.

## Layout

- Hero-like workspace header with teacher name, current teaching period, and quick actions.
- Top metric row for active students, live courses, pending grading, and content drafts.
- Main two-column area with today’s teaching queue and course performance.
- Secondary panel for assistant activity, student alerts, and upcoming deadlines.

## Core Widgets

- Today’s Plan: scheduled classes, lessons to publish, assignments due.
- Pending Grading: submissions, quiz reviews, rubric tasks.
- Course Performance: completion rates, engagement, average scores.
- Student Attention: low activity, missed assignments, repeated quiz failures.
- Draft Content: lessons, quizzes, assignments waiting for publishing.
- Assistant Updates: delegated tasks, notes, completed reviews.

## Premium SaaS Details

- Use purple only for primary creation actions and selected course state.
- Use blue charts for performance and completion trends.
- Use orange for due-soon and pending grading.
- Use red only for severe student risk or publishing blockers.
- Cards should be information-rich without becoming visually crowded.

## Teacher Workflows

- Create lesson from quick action.
- Resume editing draft content.
- Review submissions from pending grading widget.
- Open student detail from risk queue.
- Message assistant or cohort from contextual action.

## Responsive Behavior

- Desktop: teaching queue and analytics visible side by side.
- Tablet: top metrics remain horizontal when possible, queues stack below.
- Mobile: “Continue teaching” and “Pending grading” appear before analytics.
