# Parent Layout

The parent layout provides family-level visibility into student progress, assignments, teacher feedback, finance, and alerts.

## Sidebar

- Navigation groups: Family Overview, Children, Progress, Assignments, Payments, Messages, Reports.
- Include child switcher when more than one student is linked.
- Show concise status indicators per child.

## Topbar

- Sticky topbar with selected child or family context, notifications, search, and profile menu.
- Search should prioritize child records, courses, invoices, reports, and messages.
- Include clear date range controls on report-heavy pages.

## Quick Actions

- View child progress.
- Pay invoice.
- Message teacher.
- Download report.
- Review alerts.

## Notifications

- New teacher feedback.
- Missed or overdue assignments.
- Payment due.
- Attendance or engagement concern.
- New monthly report.

## Profile Menu

- Parent profile.
- Linked students.
- Billing settings.
- Notification preferences.
- Sign out.

## Responsive Behavior

- Desktop: family dashboard with child switcher and multi-panel overview.
- Tablet: child switcher moves to topbar, cards stack into two columns.
- Mobile: child selector becomes prominent, finance and alerts remain reachable in first screen.
