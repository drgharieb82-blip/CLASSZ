# Assistant Layout

The assistant layout supports delegated teaching operations such as grading, roster support, content preparation, and student follow-up.

## Sidebar

- Navigation groups: Dashboard, Assigned Courses, Tasks, Students, Submissions, Reports.
- Show supervising teacher context.
- Clearly separate available actions from restricted teacher-only actions.
- Include task count badges for pending work.

## Topbar

- Sticky topbar with assigned workspace title, task search, notifications, and profile menu.
- Search should prioritize assigned students, submissions, lessons, and tasks.
- Include permission context so assistants understand current scope.

## Quick Actions

- Review submissions.
- Add student note.
- Prepare lesson draft.
- Flag student issue.
- Send update to teacher.

## Notifications

- New assigned task.
- Teacher comment.
- Submission ready for review.
- Student support request.
- Permission or scope change.

## Profile Menu

- Assistant profile.
- Assigned teachers.
- Permission summary.
- Notification preferences.
- Sign out.

## Responsive Behavior

- Desktop: task-first layout with sidebar and work queue.
- Tablet: compact navigation rail, task filters stay visible.
- Mobile: task queue becomes the first screen, secondary modules move into drawer.
