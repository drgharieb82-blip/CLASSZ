# Student Layout

The student layout is a focused learning desk that emphasizes current lessons, assignments, progress, and upcoming work.

## Sidebar

- Navigation groups: Dashboard, My Courses, Lessons, Assignments, Quizzes, Progress.
- Show current student identity and learning streak when available.
- Keep navigation simple and low-noise.
- Highlight the next recommended learning action.

## Topbar

- Sticky topbar with page title, course search, notifications, and profile menu.
- Search should prioritize enrolled courses, lessons, assignments, and quiz history.
- Include theme toggle and accessible mobile menu trigger.

## Quick Actions

- Continue learning.
- Submit assignment.
- Start quiz.
- View progress.
- Ask for help.

## Notifications

- Assignment due soon.
- New lesson published.
- Quiz result available.
- Teacher feedback.
- Payment or access issue when relevant.

## Profile Menu

- Student profile.
- Progress summary.
- Account settings.
- Linked parent visibility status.
- Sign out.

## Responsive Behavior

- Desktop: sidebar plus dashboard grid with current learning path and upcoming work.
- Tablet: compact sidebar rail and stacked progress panels.
- Mobile: bottom-priority navigation or drawer, large continue button, minimal visual clutter.
