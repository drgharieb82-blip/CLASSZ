# Admin Layout

The admin layout is the operational command center for platform governance, user management, analytics, finance, and system configuration.

## Sidebar

- Persistent desktop sidebar with CLASSZ branding at the top.
- Navigation groups: Overview, Users, Courses, Finance, Reports, Notifications, Settings.
- Include visible role indicator: Admin.
- Include a quick create action for inviting users or creating administrative records.
- Use selected navigation state with the CLASSZ purple gradient, supported by neutral surfaces around it.

## Topbar

- Sticky topbar with page title, breadcrumbs, global search, notifications, and profile menu.
- Global search should support users, teachers, courses, payments, and reports.
- Include environment indicator in non-production environments.
- Include theme toggle for dark and light mode.

## Quick Actions

- Invite user.
- Create course shell.
- Export report.
- Review pending approvals.
- Open system settings.

## Notifications

- Prioritize system warnings, failed payments, approval requests, support issues, and high-risk student alerts.
- Notification panel should support unread filter, severity filter, and direct navigation to source records.

## Profile Menu

- Admin profile.
- Organization settings.
- Security settings.
- Theme preference.
- Sign out.

## Responsive Behavior

- Desktop: full sidebar, sticky topbar, multi-column dashboard grid.
- Tablet: sidebar collapses into icon rail, topbar search remains visible.
- Mobile: sidebar becomes drawer, search opens as overlay, quick actions collapse into a menu.
