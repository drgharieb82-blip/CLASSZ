# Teacher Layout

The teacher layout is a teaching studio for courses, lessons, cohorts, assignments, student progress, and assistant collaboration.

## Sidebar

- Persistent desktop sidebar focused on daily teaching workflows.
- Navigation groups: Dashboard, Courses, Lessons, Assessments, Students, Assistants, Reports.
- Show active teacher workspace and current academic period.
- Include quick access to recently edited courses and lesson drafts.

## Topbar

- Sticky topbar with current workspace title, course/cohort switcher, search, notifications, and profile menu.
- Search should prioritize courses, lessons, students, assignments, and quiz results.
- Include compact indicators for draft content, pending grading, and upcoming classes.

## Quick Actions

- Create lesson.
- Create assignment.
- Create quiz.
- Message cohort.
- Review submissions.

## Notifications

- Pending submissions.
- Student questions.
- Assistant updates.
- Course publishing issues.
- At-risk student alerts.

## Profile Menu

- Teacher profile.
- Teaching settings.
- Assistant permissions.
- Earnings overview when finance is available.
- Sign out.

## Responsive Behavior

- Desktop: full teaching navigation and dashboard grid.
- Tablet: sidebar collapses to rail, course switcher remains top-level.
- Mobile: drawer navigation, quick action menu, dashboard cards stacked by urgency.
